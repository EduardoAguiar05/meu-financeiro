Como os dados são armazenados

Esta versão é um único arquivo HTML, sem servidor. Os dados são gravados no localStorage do navegador, associados à origem do arquivo. Eles não são sincronizados entre computadores ou navegadores e podem ser apagados ao limpar dados do site.

Os saldos são calculados a partir de lançamentos, transferências, aportes e pagamentos. As compras no crédito entram na fatura e no limite utilizado; o pagamento da fatura não é contabilizado duas vezes como gasto.
